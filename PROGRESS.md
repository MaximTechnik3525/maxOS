# maxOS Progress & Architectural Roadmap

## 🏆 Достижения (Уже реализовано)
1. **64-bit Long Mode Kernel:** Операционная система полностью работает в 64-битном режиме (Long Mode) с поддержкой инструкций `syscall/sysret`.
2. **Файловая система maxFS 2.0:** Безопасная ФС, живущая на жестком диске. Решены проблемы с перекрытием LBA секторов между ядром и метаданными (Superblock/Inode/Bitmap сдвинуты).
3. **Hardware & Drivers:**
   - Кастомный MBR загрузчик, загружающий ядро 480 КБ напрямую в память без GRUB (при загрузке с HDD).
   - ATA PIO драйвер (чтение/запись на жесткий диск и CD-ROM).
   - PS/2 драйверы клавиатуры и мыши (с поддержкой колесика).
   - PIT (Programmable Interval Timer) на 1000 Hz для преемптивной многозадачности.
4. **Memory Management (MMU & PMM):**
   - Битмап-аллокатор физической памяти (PMM).
   - 4-килобайтный страничный маппинг (Paging). Защита `NULL`-указателя.
   - Динамическое выделение памяти для ядра (`kmalloc`/`kfree`).
5. **Process Isolation & Tasking:**
   - Каждая задача имеет собственный регистр `CR3` и свое изолированное виртуальное адресное пространство.
   - Аппаратное переключение контекста между процессами (Ring 0 / Ring 3).
   - Добавлен парсер `ELF64` (готов к загрузке внешних приложений).
6. **GUI & Installer:**
   - VESA Linear Framebuffer (1024x768x16).
   - Полноценный установщик (форматирует диск, копирует ядро, делает аппаратную перезагрузку через порт 0x64).

## 🚀 Текущая фаза: Глобальный рефакторинг "User Space & Event Loop"

Сейчас все приложения вкомпилированы в ядро, а оконный менеджер `maxp` вызывает их функции напрямую. Наша цель — сделать из maxOS классическую ОС микроядерного/гибридного типа.

### Этап 1: Стандартная библиотека (libc) [В ПРОЦЕССЕ]
- [x] Создана папка `src/user/libc/` с заголовочными файлами `stdio.h`, `stdlib.h`, `string.h`.
- [x] Написан `libc.c` — обертка над системными вызовами `syscall`.
- [x] ИСПРАВЛЕН КРИТИЧЕСКИЙ БАГ: Kernel Panic / BSOD при прерывании системных вызовов (`syscall`). Добавлены индивидуальные стеки системных вызовов (`kstack`) для каждого процесса. 

### Этап 2: Рефакторинг Window Manager (Очередь событий) [ГОТОВО]
- [x] Ядро собирает события (клики/клавиши) и складывает в очередь.
- [x] Приложения `Калькулятор` и `SysInfo` полностью переведены на бесконечный цикл `while(1)` с чтением событий через `maxos_get_event()`.
- [x] ИСПРАВЛЕН КРИТИЧЕСКИЙ БАГ: Устранено голодание задач (Priority Starvation) в планировщике `task.c`, устранён бесконечный цикл затирания экрана обоями, окна открываются мгновенно и плавно реагируют на ввод.

### Этап 3: Изоляция приложений в ELF-файлы
- Перенос программ (`pong.c`, `notepad.c`, `calc.c`, `explorer.c`) из папки `src/apps/` в отдельную песочницу.
- Сборка каждой программы как независимого `.elf` файла, линковка с `libc.o`.
- Запись этих `.elf` файлов на `maxFS` во время установки.
- При клике по иконке приложения ядро будет находить файл на диске, парсить его через `elf.c`, выделять новые страницы, копировать код и передавать управление в Ring 3.

## 🔌 Дорожная карта аппаратной поддержки (Hardware & Drivers)

Цель: превратить maxOS во всеядную систему с поддержкой разнообразного реального и виртуального оборудования.

### 1. Фундамент: Сканер шины PCI (PCI Bus Enumeration)
- [ ] Опрос шин (Bus 0..255, Device 0..31, Function 0..7) через порты конфигурации `0xCF8` / `0xCFC`.
- [ ] Чтение конфигурационного пространства: `Vendor ID`, `Device ID`, `Class Code`, `Subclass`, `BAR0..BAR5`, `Interrupt Line`.
- [ ] Таблица автоматической регистрации и привязки драйверов по PCI Class / Device ID.
- [ ] Интеграция в `SysInfo`: создание экрана **«Диспетчер устройств»** со списком всего найденного оборудования.

### 2. Дисковая подсистема: SATA (AHCI)
- [ ] Обнаружение AHCI контроллера на шине PCI (`Class 01h`, `Subclass 06h`, `ProgIF 01h`).
- [ ] Маппинг регистров контроллера через MMIO (ABAR / BAR5) в адресное пространство ядра.
- [ ] Инициализация HBA (Host Bus Adapter), сброс портов и определение типов накопителей (SATA HDD/SSD, SATAPI CD-ROM).
- [ ] Настройка таблиц дескрипторов памяти (PRDT) и кольцевых очередей команд (Command List).
- [ ] Переход от медленного побайтового ATA PIO к аппаратному прямому доступу к памяти (DMA).

### 3. Аудиоподсистема: Настоящий PCM стереозвук (Прощай, пищалка!)
- [ ] **AC97 драйвер** (`Class 04h`, `Subclass 01h`) — простой и надёжный контроллер для виртуалок (QEMU/VirtualBox) и ПК 2000-х.
- [ ] **Intel HDA (High Definition Audio)** (`Class 04h`, `Subclass 03h`) — современный стандарт на всех ПК и ноутбуках с 2005 года.
- [ ] Воспроизведение 16-битных WAV аудиофайлов через DMA кольцевой буфер.
- [ ] Озвучка системы: звук запуска maxOS, клики по кнопкам, звуковые эффекты в играх (Pong).

### 4. Сетевая подсистема: Сеть и Интернет
- [ ] Драйвер сетевой карты **Intel e1000** (82540EM) или **Realtek RTL8139** (`Class 02h`, `Subclass 00h`).
- [ ] Приём и передача Ethernet-фреймов через кольцевые буферы дескрипторов (TX/RX Descriptors).
- [ ] Базовый сетевой стек: Ethernet, ARP (разрешение IP-MAC), IPv4, ICMP (команда `ping`).

### 5. Шина USB (Universal Serial Bus)
- [ ] Поддержка хост-контроллеров **UHCI** (USB 1.1) и **xHCI** (USB 3.0 / современное железо).
- [ ] USB HID протокол: избавление от устаревшего контроллера PS/2 для мыши и клавиатуры.
- [ ] USB Mass Storage: чтение USB-флешек как блочных устройств в файловой системе maxFS.
