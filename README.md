maxOS is simple os written on Netwide Assembler and C.
To launch OS you need download the project and start build.bat. For this you need qemu emulator.
You can write your own programms for maxOS. You need to enable write mode and enter commands. Also you can just simple write text.
List of avaivable commands: theme1 (theme2, theme3, theme4, theme5) - changes  system theme; format - format virtual maxFS disk; clear - just redrawing screen; winr (winl, winu, wind) - moves window on 50 pixels; speaker - enables pc speaker for 250ms on 750gHz (or like, i don't know name).
